# TsinghuaHelper

清华社英语学习网站的浏览器用户脚本，当前版本 **0.1.0**。适配 `https://www.tsinghuaelt.com/` 的部分练习与页面操作。

支持填空、单选、多选、判断、拖拽配对、主观文本、普通录音，以及基于音频回环的跟读和角色扮演。网站更新可能导致功能失效，请先在单页验证，再开启连续处理。

## 安装

**[点击安装 TsinghuaHelper](https://raw.githubusercontent.com/FGFRN/TsinghuaHelper/master/tsinghua-fill.user.js)**

1. 在浏览器中安装支持用户脚本的扩展，例如 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击上面的一键安装链接，在扩展提供的安装页面确认安装。
3. 如果浏览器只显示源码，请在扩展中新建脚本，将源码完整粘贴并保存。部分浏览器还需要按扩展提示开启用户脚本权限。
4. 打开课程页面并刷新，确认出现“学习助手”面板。
5. 禁用旧版本或其他重复执行同类操作的脚本，避免重复填写与提交。

安装链接指向本仓库 `master` 分支的原始脚本。首次发布时需要将 `tsinghua-fill.user.js` 一并推送；仓库改名或分支变更后应同步修改链接。

## 基本使用

- 点击开始按钮处理当前页；点击停止请求终止后续操作。已经发出的请求仍可能完成。
- **成功后自动下一题**：客观题确认正确，或主观／语音题确认提交后继续。提交成功不等于评分达标。
- **失败后自动下一题**：默认关闭。开启后记录异常并尝试跳过；仍在录音或无法确认翻页时可能停止。
- **运行日志**：查看、复制、清空操作记录；异常记录红底置顶。日志与样本缓存保存在当前页面内存中，刷新后清空。
- 标题栏可拖动，最小化后变为可拖动圆形按钮。紫色表示运行，绿色表示完成，红色表示异常。
- 所有提交经过统一等待入口。提交失败和限频提示会按脚本设置等待重试，并设重试上限。

## 跟读与角色扮演

“跟读题设置”中的**自动完成跟读题默认关闭**。开启前需要确认已完成下方的音频设备串联。

此功能把样本播放声音送进网站选择的录音设备。得到的评分反映样本及传输质量，不代表使用者本人的发音能力。是否适用于具体课程，请按课程要求判断。

跟读处理顺序：确认录音状态 → 等待 1 秒 → 播放对应样本 → 播放结束后等待 1 秒 → 停止录音 → 等待评分 → 下一句。

角色扮演会关联前页跟读数据中的角色、台词和样本资源。请先加载对应跟读页，再进入角色扮演页；刷新或直接打开角色页可能导致样本缓存不足。

## 音频串联准备：OBS Studio + VB-CABLE

以下是 Windows 的一种配置方案。不同版本的设置名称可能略有差异。无需直播，也无需点击 OBS 的“开始录制”，只需要让 OBS 的音频捕获和监听保持工作。

### 1. 先理解声音走向

```text
浏览器样本声音
    ↓ 输出到实际耳机／扬声器
OBS 捕获该输出设备的音频
    ↓ OBS 音频监听
CABLE Input（虚拟播放设备）
    ↓ VB-CABLE 内部转发
CABLE Output（虚拟录音设备）
    ↓ 浏览器将它选为麦克风
网站录音与评分
```

| 设置位置 | 选择的设备 |
|---|---|
| Windows／浏览器声音输出 | 实际使用的耳机或扬声器 |
| OBS 音频输出捕获 | 与浏览器输出相同的耳机或扬声器 |
| OBS 监听设备 | **CABLE Input** |
| 网站／浏览器麦克风 | **CABLE Output** |

名称容易混淆：`CABLE Input` 是把声音送进线缆的**播放端**；`CABLE Output` 是其他应用读取声音的**录音端**。这是 VB-CABLE 的设备命名，不要根据“输入／输出”中文习惯反选。[官方说明](https://vb-audio.com/Cable/)

### 2. 安装软件

1. 从 [OBS Studio 官网](https://obsproject.com/download)安装 Windows 版本。
2. 从 [VB-Audio 官网](https://vb-audio.com/Cable/)下载 **VB-CABLE Virtual Audio Device** 驱动包；本方案只需一条基础虚拟线缆。
3. 将驱动压缩包完整解压。按系统架构选择安装程序，以管理员身份运行并安装驱动。
4. 安装后重启电脑，再打开 Windows“设置 → 系统 → 声音”。
5. 确认输出设备列表有 `CABLE Input`，输入设备列表有 `CABLE Output`。名称后面可能带有 `VB-Audio Virtual Cable`。

完整解压、管理员安装和重启是厂商要求的步骤。[安装说明](https://vb-audio.com/Cable/)

### 3. 保持浏览器输出到实际耳机

1. Windows“设置 → 系统 → 声音”中，将日常输出设备设为实际耳机或扬声器。
2. 播放一段网页音频；在“音量混合器”里确认浏览器输出到了这个设备，且没有静音。
3. 后面 OBS 捕获的必须是同一个设备。建议明确选择具体设备名，减少系统默认设备变化的影响。
4. 测试时关闭音乐、通知音和其他音视频页面。此方案捕获的是所选设备的声音，其他声音也会一起进入录音。

### 4. 配置 OBS 音频捕获

1. 新建一个场景，例如“网站音频回环”。
2. 打开“设置 → 音频”，将不需要的全局“桌面音频”和“麦克风／辅助音频”禁用，以免同一路声音被重复捕获。
3. 在“来源”区域点击 `+`，选择“音频输出捕获”，命名为“浏览器输出”。
4. 设备选择第 3 步的实际耳机／扬声器。**不要选 CABLE Input。**
5. 播放网页样本，确认 OBS“混音器”中这一来源的电平条随声音变化。

### 5. 将 OBS 监听送入虚拟线缆

1. 在 OBS“设置 → 音频 → 高级”中找到“监听设备／Monitoring Device”，选择 **CABLE Input (VB-Audio Virtual Cable)**，应用设置。
2. 在混音器菜单或“编辑”菜单打开“高级音频属性”。
3. 找到“浏览器输出”这一行，将“音频监听”设为**仅监听（输出静音）／Monitor Only (mute output)**。若版本用独立监听按钮，则开启该来源的监听。
4. 这里“输出静音”指 OBS 的录制／直播输出，不是停止向监听设备发送音频。本方案不需要录制或直播。
5. 其他来源保持“监听关闭”，特别是麦克风和虚拟线缆录音端。

OBS 的监听会把指定来源送往设置中的监听设备。[官方混音器说明](https://obsproject.com/kb/audio-mixer-guide)

**避免反馈回路：不要同时让 OBS 捕获 CABLE Input，再把捕获结果监听回 CABLE Input；也不要把 CABLE Output 的录音输入监听回同一根线缆。** 否则可能出现回声、尖啸或重复叠加。[OBS 社区说明](https://obsproject.com/forum/threads/volume-during-capture.158179/)

### 6. 网站麦克风选择 CABLE Output

1. 在浏览器的麦克风设备设置中选择 **CABLE Output (VB-Audio Virtual Cable)**。Edge 可在设置中搜索“麦克风”，Chrome 同理。
2. 如果网站有自己的麦克风选择器，也选择 CABLE Output。
3. 如果浏览器只使用“系统默认”，在 Windows 声音设置中将输入设备设为 CABLE Output，然后重启浏览器。
4. 为该网站允许麦克风访问；若被系统阻止，检查 Windows“隐私和安全性 → 麦克风”中浏览器的访问权限。
5. 改变设备后刷新课程页，让网站重新创建录音器。

### 7. 开启脚本回环模式

1. 展开脚本面板的“跟读题设置”。
2. 确认“回环录音模式”已勾选。首次安装默认开启，已有设置会保留。
3. 更改这个开关后必须刷新页面。该模式会在网站申请音频输入时请求关闭回声消除、降噪和自动增益，减少回环声音被当成回声消除的情况。
4. 开始录音后查看日志中的实际设置；具体是否生效取决于浏览器和设备。
5. 此时先不要开启连续自动处理，先完成下面的单句测试。

### 8. 单句测试

1. 保持 OBS 打开，并确认电平正常。
2. 在网站手动开始一句录音，等录音动画出现。
3. 在脚本音频列表点击对应样本的“播放”，等待播放结束后停止网站录音。
4. 等待评分结果，回放网站保存的录音，检查声音是否完整，有没有静音、回声或断续。
5. 若列表为空，切到别页再返回，让脚本捕获题目接口数据；等待片刻后点击“刷新音频列表”。
6. 确认单句正常后，开启“自动完成跟读题”，在确认弹窗选择“已做好准备”。首次建议关闭“成功后自动下一题”，观察一整页的结果。

### 9. 使用结束后恢复

1. 停止脚本和样本播放，关闭 OBS 的音频监听或退出 OBS。
2. 将浏览器／Windows 的输入设备恢复为真实麦克风，避免会议或通话收不到自己的声音。
3. 不再使用回环时，关闭脚本回环模式并刷新网页，让网站重新创建正常录音流。

## 常见问题

| 现象 | 优先检查 |
|---|---|
| OBS 电平不动 | 浏览器是否有声音；捕获设备是否与浏览器实际输出一致 |
| OBS 有电平，网站没声音 | 监听是否开启；OBS 监听选 CABLE Input、网站麦克风选 CABLE Output |
| 本地能听到样本，网站录音断续 | 回环模式是否开启并刷新；实际音频处理设置；是否有蓝牙通话模式切换 |
| 录音回声或音量越来越大 | 重复来源、Windows“侦听此设备”、线缆自身被再次捕获造成反馈 |
| 录音爆音 | 降低播放器或 OBS 来源音量，避免电平持续顶满 |
| 评分为零但已提交 | 请求保存成功不等于有效录音或评分通过；先回听音频、查看错误提示 |
| 样本地址获取失败 | 网站登录、资源接口权限及地址有效期；保留日志方便排查 |
| 角色扮演缺少样本 | 先加载同组跟读页；刷新会清空当前样本缓存 |

不要用降低系统总音量至零代替正确路由：不同捕获方式可能受音量设置影响，应以 OBS 电平和网站实际录音测试为准。
